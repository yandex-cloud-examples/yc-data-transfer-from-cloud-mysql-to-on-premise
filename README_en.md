# Migrating data to a third-party MySQL cluster through Yandex Data Transfer

With [Data Transfer](https://yandex.cloud/en/docs/data-transfer), you can transfer a database from your [Yandex Managed Service for MySQL](https://yandex.cloud/en/docs/managed-mysql) cluster to a third-party MySQL cluster. See [this tutorial](https://yandex.cloud/en/docs/data-transfer/tutorials/managed-mysql-to-mysql) to learn how to set up the solution with Terraform. This repository contains the configuration file you will need: [data-transfer-mmy-mysql.tf](data-transfer-mmy-mysql.tf).
